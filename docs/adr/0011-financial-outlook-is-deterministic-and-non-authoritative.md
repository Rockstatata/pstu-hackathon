# Financial Outlook is deterministic and non-authoritative

Financial Outlook and Goal Projections are read-only interpretations layered over completed Journal Entries. Every displayed fact and projection comes from disclosed integer-poisha formulas and User-controlled assumptions; there is no model, hidden score, or write path into Transfers, Scheduled Transfers, Accounts, or the Ledger. This preserves reproducibility and privacy while making clear that a projection is an educational estimate rather than financial advice or a promise.
